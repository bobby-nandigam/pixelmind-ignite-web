# PixelMind Labs

Concept marketing site for "PixelMind Labs," an AI-products studio, showcasing three product ideas (ChatMind AI, DataQuery AI, MediaAssist) plus an SDK integration example, blog, and about page.

## Stack

- Vite + React + TypeScript
- shadcn/ui + Tailwind CSS

## Running locally

1. `npm install`
2. `npm run dev`

## Notes

Front-end only. The `@pixelmind/sdk` snippets shown on the integrations page are illustrative copy, not a real published package.
